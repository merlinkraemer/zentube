# Privacy Policy — ZenTube

**Last updated: April 16, 2026**

ZenTube is a Chrome extension that hides distracting UI elements on YouTube.

## Data collection

ZenTube collects no data. It does not:

- Track your browsing activity
- Collect personal information
- Send any data to external servers
- Use analytics or telemetry
- Store anything beyond your on/off preference

## Local storage

ZenTube stores a single value — whether the extension is enabled or disabled — in Chrome's local storage. This value never leaves your device.

## Permissions

ZenTube requests one permission:

- **storage** — to remember your on/off preference across browser sessions

No host permissions, no network access, no access to page content beyond injecting a CSS stylesheet.
